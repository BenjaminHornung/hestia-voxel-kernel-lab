# Agent Rules

- Only one write agent may work in this repository at a time.
- Use one branch per work package and start from the latest accepted integration SHA.
- Run the relevant build, tests, browser E2E, and screenshot checks before committing.
- Commit and push the completed work package; implementation agents do not merge.
- Do not introduce low-poly or smooth voxel rendering.
- Do not add unplanned dependencies.
- Do not import or copy code from Weltraum-Spiel.
- Stop after completing the assigned work package.
