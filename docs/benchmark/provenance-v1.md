# Benchmark Provenance v1

JSON contracts use strict RFC 8785-style JCS bytes: UTF-8 without BOM, no trailing LF, raw UTF-16 property-key order, preserved arrays, and no Unicode normalization. Duplicate keys are rejected before parsing. Nonfinite, negative-zero, unsafe, cyclic, accessor, non-simple, and unpaired-surrogate values fail closed.

Relative bundle paths are lowercase ASCII POSIX paths. Fileset, build, and bundle SHA-256 values use versioned domains and length-prefixed frames. `bundle.sha256` is the only digest-cover exception. Verification rejects missing, extra, duplicate, symlink, special, or tampered files and never repairs a partial bundle. The supported trace artifact tuple is path suffix `traces/**/trace.json.gz`, media type `application/gzip`, and `binary-exact` serialization; `heap-snapshot` and `gpu-capture` remain fail-closed and unavailable until an evidence-backed extension/media tuple is standardized.

Source preflight binds the accepted WP04 commit/tree, exact clean porcelain-v2 status bytes, verified real repository root, available fixture/candidate filesets, and build fileset through an injectable fixed-argument command runner. Root comparison is case-insensitive only on Windows. It promotes only byte-verified semantic, path, and fileset bindings: semantic observation requires canonical fixture-contract bytes whose SHA-256 matches the supplied digest. Declared claims are never returned as observed evidence without that verification. Future owner-bound sources use unavailable structural bindings rather than fabricated SHA/path values. A validation receipt accepts actual telemetry/run/schema/registry/validator-source inputs, validates the raw canonical run against an independently constructed fixture/candidate/plan context with mandatory schema-set and registry digests, computes separate digests internally, and is deterministic/self-excluding. It has no timestamp or random identifier and is not created for an invalid or context-mismatched run.

The three normative documentation paths are `docs/benchmark/contracts-v1.md`, `docs/benchmark/provenance-v1.md`, and `docs/benchmark/third-party-ajv.md`; C08/source-pack documentation remains read-only input. Bundle timestamps require an exact real-calendar UTC roundtrip, not only a lexical date pattern. H2/H3 device selection, external attestation, immutable storage, and real performance-gate publication remain owner-bound residuals. Structurally representable profiles without observed bindings are never performance-eligible. BR01 makes no runtime, browser, timing, aggregation, or performance claim.
